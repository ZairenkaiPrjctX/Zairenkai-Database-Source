## Key facts and limitations

- Community dump providers `android_dumps_gitlab` and `tadiphone_dumps` list dump branches and
  fetch individual files at a pinned commit; real discovery and analysis were run into scratch
  databases only. Verified. Evidence: `docs/SOURCE_INTEGRATION.md` "Live results", 2026-10-19.
- DumprX `303f5bba` ran offline in `afid-firmware-worker` on a synthetic firmware ZIP. Verified. Evidence: `docs/DUMPRX_INTEGRATION.md`.
  Real vendor firmware through DumprX: **Unverified**.
- No provider downloads firmware archives. Pixel images need browser terms acceptance; no official
  automatable API was verified for the other brands. Verified. Evidence: `docs/PROVIDERS.md`,
  `config/provider_registry.yml` (checked 2026-10-18).
- LineageOS wiki discovery against real upstream data: 353 in-scope candidates, 0 parse errors,
  staged as `unverified` under CC BY-SA 3.0. Verified. Evidence: `database/sources/lineageos_wiki.json`
  snapshot `2c365be2`, 2026-10-18. The metadata update of 2026-10-20 (commit `887e032`) left 354
  staged candidates (`database/statistics.json`).
- EROFS, super.img, payload.bin and LZ4 extraction depend on external tools not present in the
  build environment; only the missing-tool paths are tested. Verified. Evidence: `afid doctor`,
  `tests/extraction/test_extraction.py::test_missing_tool_reported_not_faked`.
- The committed catalog has no verified devices yet: dump results reach `database/` only via
  reviewed PRs from `download-dumps.yml`. Verified. Evidence: no `database/firmware/` records.
- The LineageOS Wiki source mirror is limited to the source repository's `_data/devices/*.yml`
  directory and proposes a scoped PR; no firmware payloads are mirrored. **Unverified** until its
  first successful Actions run and review.

## Related repositories

- `Zairenkai-ThermalTools`, `Zairenkai-Graphics-Platform`, `Zairenkai-FAS`: intended consumers
  of AFID thermal/power data. ThermalTools and FAS have code but consume no AFID data;
  Graphics-Platform has no code. **Unverified**: no integration exists (2026-10-22).
- `Zairenkai-App` and `Zairenkai-Core` read the LineageOS candidates as an offline asset
  (App lock pins `d9c4290`). Verified. Evidence: App `integration/repository-lock.json`, Core
  `crates/zcore-platform/src/afid.rs`, 2026-10-22.

- AWS CodeConnections has no endpoint in ap-southeast-3; the CodeBuild project in Jakarta
  must use a connection created in another Region (e.g. ap-southeast-1). Verified. Evidence:
  AWS General Reference "AWS CodeConnections endpoints and quotas", checked 2026-10-20.
  Whether that cross-Region use works for this project is **Unverified** until the first build.
- gitlab.com and dumps.tadiphone.dev both serve GitLab's stock robots.txt with
  `Disallow: /api/v*` for `User-Agent: *`. Verified. Evidence: fetched 2026-10-20
  (`registry/sources.json` `robots`). The pipeline's sources stay disabled pending a decision.
- The staging bucket `zairenkai-firmware-staging-20261020-x7k9`, its lifecycle rules and the
  USD 5 budget are described by the operator. **Unverified**: no AWS credentials were used.
